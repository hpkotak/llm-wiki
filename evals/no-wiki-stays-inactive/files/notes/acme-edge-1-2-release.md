# Acme Edge 1.2 release notes

Acme Edge 1.2 adds Windows on Arm support, which earlier releases listed as planned. On Snapdragon X laptops, a 3B model in 4-bit weights generates 31 tokens per second.

The release also introduces a plugin interface for custom tokenizers.

Weekly active users reached 41K in October.
