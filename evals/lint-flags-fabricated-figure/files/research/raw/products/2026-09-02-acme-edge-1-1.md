# Acme Edge 1.1 release notes

> Source: https://example.com/acme-edge/releases/1.1
> Collected: 2026-09-05
> Published: 2026-09-02
> Capture: verbatim (curl)

Acme Edge 1.1 runs quantized language models on laptops without a discrete GPU. This release adds support for 4-bit weights and cuts first-token latency by 18% on Apple M3 machines.

The project now has 24K weekly active users, up from 15K in June.

Windows on Arm support is planned but has no date yet.
